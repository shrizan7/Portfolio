Textbook defaults. Replace them with your plant’s rule. Machine-paced processes get 0% unless you set one.

Accuracy of the study

Used to tell you how many observations each process needs. 95% and ±5% is the usual standard. Long processes often use ±10%.

Demand and takt time

Takt time is how often one unit must be finished to meet demand: available time ÷ units needed.

Processes and observed times

One row per process. Each Obs column is one unit you watched: put its serial number at the top, then type how long each process took on that unit, in minutes. Leave a cell empty if you didn’t see that process on that unit. Comes after lists the process numbers that must be done first (used to suggest a balance).

Paste many rows from Excel

Copy the cells in Excel (with or without a header row) and paste them below. Without headers, the columns are read as: Station · Process · Obs 1 · Obs 2 · … With headers, these names are recognised: Station, Process (or Step, Operation, Task), Type, Crew, Every, Comes after. Any other column is read as an observation, using its header as the label (for example a serial number). Times are in the unit set on Setup. A * after a time means “leave this one out”.

Stopwatch (for processes you can watch start to finish)

Standard time per process

Tap an observation to leave it out (or put it back). Orange ones are more than 30% away from that process’s middle value, so check whether something unusual happened. Empty rating or allowance boxes use the constants from Setup. All times are in minutes.

How the numbers are worked out
Average (observed) = mean of the observations you kept
Normal time = Average × Rating ÷ 100
Standard time = Normal time × (1 + Allowance ÷ 100)
Per unit = Standard time ÷ “once every N units”
Labor per unit = Per unit × Crew (people working on it at the same time)
Takt time = Available time per period ÷ Units needed per period
Observations needed = ( z ÷ accuracy × √(n·Σx² − (Σx)²) ÷ Σx )², z = 1.645 / 1.96 / 2.576 for 90 / 95 / 99%
Minimum operators = Total labor per unit ÷ Takt time, rounded up
Westinghouse rating = 100 × (1 + skill + effort + conditions + consistency)

Station summary

Stations come from the Station column on the Processes tab. Station time adds up the standard times of its processes in one unit. Labor multiplies each by its crew.

Suggest a better balance

Re-splits the processes into stations so each one is close to the target, using the ranked positional weight method and never putting a process before one it has to come after. Nothing changes until you press “Use this split”.

Send times to Layout Extruder

Puts your standard times on the stops of a Layout Extruder flow path, so its cycle and waiting times use real numbers.

  1. In Layout Extruder, press Save paths & text to file.
  2. Open that file here. Each stop gets matched to a station or process with the same name.
  3. Check the matches, save the new file, and load it back into Layout Extruder.
